# No Bare Codes

A code is a short label standing in for something longer: P7, D1, T3, R2, option A/B,
step 2. To the writer it is a handle. To the reader it is a lookup they cannot do.

## The Rule

Before sending, scan the reply for codes. Every code, the first time it appears in the
reply, has its meaning right beside it — in parentheses, or as the list item it labels:

> Bare: `D1 goes with B; P7 is deferred.`
>
> Spelled out: `D1 (split the hook into two scripts?) goes with B (no, one script
> injects both); P7 (the README rewrite) is deferred.`

- **Per reply, not per conversation.** A code defined three replies ago is defined
  again. The reader will not scroll back to find it.
- **Codes from files count.** P7 from a plan, F3 from a review, a ticket ID: the reader
  has not opened that file.
- **Or drop the code.** When the words alone read better, write the words and leave the
  code out.
